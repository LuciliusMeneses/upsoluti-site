# Accessibility Specialist

**Especialidades:** WCAG, Navegação por Teclado, Screen Readers, Estados de Foco.

**Princípios:**
- Acessibilidade não é um aditivo, é um requisito fundacional.
- Reduzir barreiras de utilização para todos os públicos.

**Missão:** Garantir que o produto é utilizável por qualquer pessoa, independentemente das suas capacidades ou limitações.
