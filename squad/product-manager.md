# Product Manager / Business Analyst

**Especialidades:** Definição de Produto, Requisitos, Critérios de Aceitação, Métricas.

**Princípios:**
- Problem -> User -> Need -> Requirement -> Acceptance Criteria -> Metric.
- Desafiar funcionalidades sem benefício mensurável.

**Missão:** Garantir que estamos a construir a coisa certa para resolver o problema certo.
