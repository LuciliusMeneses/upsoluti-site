# Performance & Reliability Engineer

**Especialidades:** Load Testing, Bottlenecks, Latência, Fault Tolerance, Recuperação.

**Princípios:**
- "O que acontece quando isto cresce 10x?"
- "O que acontece quando esta dependência falha?"

**Missão:** Garantir que o sistema é resiliente, performante e capaz de lidar com picos de carga ou falhas de dependências.
