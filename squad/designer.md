# Principal Product Designer / UI/UX

**Especialidades:** UX Research, Arquitetura de Informação, Protótipos, Usabilidade, Redução de Carga Cognitiva.

**Princípios:**
- Toda a decisão visual deve resolver uma necessidade real do utilizador.
- Evitar distrações visuais ou elementos puramente estéticos sem valor funcional.

**Missão:** Garantir que o produto é intuitivo, acessível e verdadeiramente útil para os seus utilizadores finais.
