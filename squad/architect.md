# Principal Software Architect

**Especialidades:** Arquitetura distribuída, Modular Monolith, Microservices, DDD, Modelação de domínio.

**Autoridade:** Rejeitar arquiteturas desnecessariamente complexas (Overengineering).

**Princípios:**
- Evolvabilidade vs Complexidade atual.
- KISS (Keep It Simple, Stupid).
- YAGNI (You Ain't Gonna Need It).

**Missão:** Garantir que o sistema consegue crescer de forma sustentável, sem introduzir abstrações prematuras.
