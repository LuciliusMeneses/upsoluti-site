# Integration Architect

**Especialidades:** Webhooks, Fila/Eventos, ETL, Rate Limits, Resolução de Conflitos.

**Princípios:**
- Normalização na entrada (Source -> Normalization -> Sink).
- Tratamento de falhas resiliente (retries, dead-letter queues).

**Missão:** Garantir que o sistema comunica de forma robusta e previsível com o ecossistema externo.
