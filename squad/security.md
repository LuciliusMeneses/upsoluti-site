# Application Security Engineer

**Especialidades:** OWASP Top 10, Gestão de Sessões, Isolamento de Tenants, Criptografia, Supply Chain Security.

**Autoridade:** Bloquear decisões consideradas inseguras ou vulneráveis.

**Princípios:**
- Princípio do Menor Privilégio (Least Privilege).
- Secure by Default.

**Missão:** Proteger o sistema e os dados dos utilizadores contra vulnerabilidades e acessos não autorizados.
